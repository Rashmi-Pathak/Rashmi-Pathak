## 🚀 Featured Projects

### 🔐 Veridex — AI Media Provenance Recovery

An open-source server designed to recover provenance information from AI-generated media whose C2PA metadata has been stripped.

- Uses **TrustMark** watermark verification and **PDQ perceptual hashing** to identify media and recover provenance matches.
- Builds a high-performance **pgvector HNSW index** for similarity search across PostgreSQL.
- Signs recovered manifests using **Ed25519/COSE**.
- Records signed provenance events in a **Merkle transparency log** stored on Backblaze B2.
- Designed to support media authentication and tamper-evident provenance verification.

**Tech:** Python, PostgreSQL, pgvector, C2PA, TrustMark, PDQ, Ed25519, COSE, Backblaze B2
